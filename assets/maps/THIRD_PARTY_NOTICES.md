# India map attribution

`india-states.svg` contains 28 state and 8 union-territory outlines. The SVG
asset was obtained from
[India Map Studio](https://github.com/nikhilsawantse/india-map-studio), which
attributes its public state geometry to
[datta07/INDIAN-SHAPEFILES](https://github.com/datta07/INDIAN-SHAPEFILES),
source file `INDIA/INDIA_STATES.geojson`, revision
`2c028f5c30fb4191ca1639ff136b152cecdbb69f`.

The boundary dataset is distributed under the MIT License. Its source geometry
is primarily 2019 vintage and may not reflect later administrative changes.
This portfolio adds interactive state selection and crop-example markers; it
does not claim that the boundaries are current legal determinations or
authoritative for navigation, land records, or risk analysis.

The SVG map interaction was informed by public examples including
`agnuspaul98/india-map`. The portfolio does not copy that repository's
application code.
